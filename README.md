--------------------------------------------------------------
 3. CÓMO APLICAR EL PARCHE
--------------------------------------------------------------

 1. Hacé una copia de tu ROM original. El parche modifica el
    archivo.
 2. Abrí un parcheador IPS, por ejemplo:
      - Rom Patcher JS (en el navegador):
        https://www.marcrobledo.com/RomPatcher.js/
      - Floating IPS (Flips), para Windows.
      - Lunar IPS, para Windows.
 3. Elegí la ROM y el archivo CardFighters_ES.ips, y aplicá.
 4. Si querés, verificá el CRC32 del resultado con el de la
    sección 2.
